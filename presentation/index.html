ferramentas06 / 14
ambiente de trabalho

Dois mundos: a VM que fabrica, o PC que grava.

build (linux)

VM Ubuntu + pmbootstrap

VirtualBox, 4 GB RAM. Toolchain oficial do postmarketOS: compila rootfs e kernel p/ o aparelho-alvo.

gravação (windows)

Android platform-tools

fastboot grava as partições em modo bootloader. adb reinicia e inspeciona.

vm · build

$ pmbootstrap install     # gera rootfs + kernel
